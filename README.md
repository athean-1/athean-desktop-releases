# Athean for Mac

[**Download Athean for Mac**](https://github.com/athean-1/athean-desktop-releases/releases/latest/download/Athean-mac-arm64.dmg)

Requires an Apple Silicon Mac and macOS 14.2 or later. An Athean account is required to sign in.

Open the downloaded disk image, drag **Athean Desktop Preview** into **Applications**, then open it. Sign in using your browser and follow the app’s permission setup.

The app is signed by **Athean LLC** and notarized by Apple. Signed versions support in-app updates for the internal rollout: when an update is ready, choose **Update now** to install and restart. Finish any active recording first.

If you previously installed an unsigned preview, replace it once using this installer. macOS may ask you to approve recording permissions again.
